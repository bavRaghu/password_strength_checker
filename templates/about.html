ABOUT THE PROJECT

Small app.
Complete pipeline.

A Flask password strength checker packaged for a DevOps CI/CD case study.

How it works

The server evaluates length and character categories, then returns general improvement suggestions. The entered password is not written to a database or application log.

Technology stack

  • Python and Flask for the web application.
  • Docker for repeatable container builds.
  • Jenkins for continuous integration and delivery.
  • Kubernetes Deployment and Service for orchestration.
  • Git for source control.

This demo uses a basic heuristic. It is not a breach checker or replacement for a password manager.
