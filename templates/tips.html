BETTER PASSWORD HABITS

Build better
security habits.

A few practical habits make accounts harder to compromise.

Use long, unique passwords

Choose a long passphrase or let a reputable password manager generate a random password. Do not reuse passwords between services.

Turn on multi-factor authentication

Use an authenticator app, passkey, or hardware security key when available.

Avoid personal details

Names, birthdays, teams, keyboard patterns, and common phrases are easy to guess.

Use a password manager

A trusted manager can generate and store unique passwords.
